# Code of Conduct

OxyBrush adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be welcoming and kind, critique work rather than people, and remember that artists and developers of every experience level are here to learn. Harassment, discrimination and personal attacks are not tolerated in any project space.

**Reporting:** until dedicated moderators are named, report incidents privately to the repository owner through GitHub. Reports are handled confidentially. A named moderation team and a project contact address will be listed here before the first public release.
