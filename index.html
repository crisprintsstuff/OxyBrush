Python Plugin System

A pure-Python client SDK (python/oxybrush) with zero third-party dependencies. Script strokes, topology, and pieces directly in Python. Use the in-app Plugins menu to launch scripts and installed plugins on the fly.

Zero dependencies & in-app UI integration

High-Res Mesh Performance

Stroke coalescing and adaptive dab budgeting (OXYBRUSH_DAB_BUDGET_MS) eliminate stroke lag during fast brush sweeps. Parallel Rayon updates, atomic stamps, and zero-copy GPU buffers keep dense sculpts buttery smooth.

Adaptive dab budget & parallel Rayon passes

Sculpting Architecture

Designed for Sculptors & Technical Artists

From non-destructive multiresolution subdivision to stroke stabilization, OxyBrush gives you the precision of industry-standard sculpting suites in a native, responsive footprint.

Multiresolution Subdivision

Press Ctrl+D to add subdivision levels; navigate up and down with D / Shift+D. Modifications made on lower levels automatically carry higher-frequency detail along.

Lazy Mouse & Stroke Modes

Stabilize strokes with an elastic drag rope, draw straight lines with Line Mode, drag out single dabs with Stamp Mode, or scatter dabs with procedural Spray dynamics.

Procedural & Custom Alphas

Seven built-in procedural alphas (Noise, Bumps, Scales, Cracks, Stripes, Rings, Square) plus import for custom 8-bit or 16-bit grayscale PNG stamp textures with follow-stroke rotation.

Masking & Face Groups

Box marquee or lasso mask selection, unmask, cavity masking, peak masking, mask blur/sharpen, and island/group isolation with Ctrl+Shift+Click.

Voxel Remesh & Decimation

Seamlessly rebuild geometry topology using background voxel remeshing or quadric decimation (e.g. 1.3M triangles down to 131k in ~6 seconds).

Atomic .oxb Project Files

Native compressed format with CRC32 checksums on every section, background autosave every 2 minutes, crash recovery, and export/import for OBJ and binary STL formats.

Engine Internals

Engineered for Modularity & Memory Safety

OxyBrush is partitioned into distinct crates designed to be lean, verifiable with headless test benches, and free of unnecessary dependencies.

crate oxy-render

wgpu & Matcap Pipeline

Modern WebGPU-native backend handling MatCaps, SSAO, cavity shading, and axis gizmos. Shaders are pre-validated via Naga with zero GPU required for CI unit tests.

cargo run -p oxy-render --example shading_timing
crate oxy-update

Verified Updates (RFC 0002)

Decoupled network updater checking GitHub releases. Verifies SHA-256 checksums, and ed25519 signatures once release signing is set up. Can be completely omitted with --no-default-features.

cargo build -p oxy-app --no-default-features
crate oxy-app

UI & Layout Engine

AccessKit screen-reader accessible interface with Standard, Compact, and Touch-friendly layouts, customizable panel shelves, and persistent settings.

oxybrush --layout standard|touch
crate oxy-ztl

Format Research

Dedicated binary format tooling and reverse-engineering research layer targeting digital clay file interoperability across sculpting ecosystems.

docs/ROADMAP.md (Phase 3)

History

Release Changelog

0.5.0-alpha 2026-11-04 LATEST
Python Plugin & Scripting System

Pure-Python SDK (python/oxybrush) with zero third-party dependencies. Top-level in-app Plugins menu, dynamic plugin auto-discovery and reload, procedural sculpting examples, and background execution.

Performance Overhaul

Stroke coalescing and adaptive dab budget (OXYBRUSH_DAB_BUDGET_MS), Rayon parallel update_after_move passes, atomic generation stamps, parallel GPU vertex packing, and zero-copy index buffers.

Customization & Agent

Keymap editor with conflict resolution, Blender/Maya MMB orbit navigation presets, local AI agent (MCP) integration, autosave off toggle, 35mm-equivalent perspective focal length, and surface-aligned brush cursor.

0.4.0-alpha 2026-11-04
Sculpting & Painting

Paint brush and mask-aware color fills, a transform gizmo for posing, quick menu at the cursor, grab through the model, Alt to move along the normal, and brush presets with shareable codes.

Viewing & Workflow

Flat shading, custom matcaps, 45° view steps, command palette, brush finder, recent files, built-in guide, strokes from empty space and opt-in update checks.

Pipeline

glTF/GLB and PLY export, OBJ objects imported as separate pieces, LOD chains, splitting pieces, and the oxybrush-cli command-line tool.

0.3.0-alpha 2026-11-02
Viewport Shading

Screen-space ambient occlusion (folds and inside shapes darken) and cavity shading (creases and pores darken, edges catch light). On by default in the view strip and remembered between sessions.

Dense Mesh Acceleration

Switching to 5.2M-triangle subdivision level accelerated from ~2.3s to ~0.7s. Adding it dropped from ~8s to ~2–4s. Level changes >1M triangles run in background threads, keeping camera orbit fluid.

Decimation & Dabs

Quadric decimation (1.3M → 131k triangles) runs in ~6s (down from 12s). Small brush dabs ~40% faster through per-dab chunk bounding box calculations.

0.2.0-alpha 2026-11-01

Subdivision Multiresolution: Added Ctrl+D to subdivide, D / Shift+D to step up and down without losing high-frequency details. Saved into .oxb project files.

UI Upgrades: Welcome starter screen (sphere, cube, plane), clay ball rendered brush previews, customizable layouts (Standard, Compact, Touch), axis view gizmo, and Raise/Carve toggles.

0.1.0-alpha 2026-11-01

New Brushes: Added Polish, Planar Trim, Topological Move, and Noise (bringing the total to 16 brushes).

Stroke Control: Introduced lazy mouse stabilization, line & stamp modes, spray dynamics, and 7 built-in procedural alphas.

macOS Universal: Released first universal .dmg supporting both Apple Silicon and Intel Macs.

0.0.1-alpha 2026-11-01

Public Launch: Initial release featuring core sculpting engine (12 brushes), XYZ/radial symmetry, multi-piece scene hierarchy, voxel remeshing, atomic .oxb storage, and wgpu matcap renderer.
