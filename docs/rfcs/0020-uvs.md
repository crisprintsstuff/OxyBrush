# RFC 0020: UVs, carried through and exported (plan)

Status: accepted; steps 1, 2, 4 and 5 landed (UVs per triangle corner,
OBJ and glTF import and export, the `UVCO` project section), and step 3 for
edits that keep the topology. Still to come: UVs through subdivision levels
and Poly Edit (step 3), and the checker display (step 6).

## Summary

OxyBrush keeps texture coordinates (UVs) from imported models, carries them
through subdivision levels and the edits that keep the topology, and writes
them back out, so a model can go from OxyBrush to a texturing or baking app
(including UDIM workflows) without losing its layout. UV editing and
unwrapping inside OxyBrush are not part of this plan.

## Why

UVs are how a model's surface maps onto textures; UDIM layouts spread them
over several texture tiles. Today OxyBrush drops UVs on import and writes
none, so a model sculpted in OxyBrush has to be unwrapped again or
transferred elsewhere before baking normal or displacement maps. Quad
subdivision levels (RFC 0019) keep the base's edge loops; carrying the UVs
along is the other half of making levels useful outside OxyBrush.

## Plan

1. **Data.** UVs are per face corner, not per point: a point on a UV seam
   has different UVs in its different faces. The mesh gains an optional
   per-triangle-corner UV list (`[Vec2; 3]` per triangle), empty for meshes
   without UVs, so sculpting and memory are unaffected when they aren't used.
   The polygon data (Poly Edit, retopology cage) gains the same per corner.
2. **Import.** OBJ `vt` and glTF `TEXCOORD_0`, including UDIM coordinates
   outside 0..1. Points that OBJ splits only because of UVs stay welded
   (their UVs live on the corners).
3. **Keep.** Brushes, undo, the transform gizmo, masking and the Deform
   window don't change topology and keep UVs as they are. Subdivision levels
   subdivide UVs with the faces: linear inside UV islands, and a choice of
   how island borders and corners smooth (the usual options are "keep
   corners" and "smooth everything but the borders"). Topology changes that
   rebuild the surface (voxel remesh, dynamic detail, decimate, booleans)
   drop UVs, with a note in the status bar, until a later step can reproject
   them.
4. **Export.** OBJ (`vt`), glTF and GLB, from any level, so the top level
   can be baked against a lower one in another app.
5. **Project files.** A new skippable section with the per-corner UVs of a
   piece (and of its base level, for pieces with levels); older versions
   skip it and open the piece without UVs.
6. **Display (small).** A checker matcap or overlay to see the UV layout on
   the model, to check that it came through.

## As built (first part)

- `MeshData::uv` / `Mesh::uvs()`: `[Vec2; 3]` per triangle, in the
  triangles' order; `Mesh::from_data` reorders them with the triangles.
  Empty for meshes without UVs, so nothing changes for them. A list whose
  length isn't the triangle count (an operation that added triangles and
  knows nothing of UVs) is dropped, so a rebuilt surface never shows
  scrambled UVs. `MeshData::retain_triangles` and `flip_winding` keep them
  right when faces are removed or turned over; `join`, `extract`,
  `delete_hidden` carry them.
- UV convention: V up (as OBJ and most tools), UDIM tiles counting up from
  0..1; glTF's V points down, so glTF import and export flip it.
- Import: OBJ `vt` by each corner's own index; glTF `TEXCOORD_0`. Points
  the file split only for UVs are welded; their UVs stay on the corners.
- Export: OBJ writes each distinct UV once as `vt` and keeps points
  shared; two triangles are written as one quad only when their shared
  edge isn't a UV seam. glTF keeps one UV per point, so points are split
  along seams on the way out (positions, normals, colors and shape keys
  copied). Quantized and meshopt glTF keep UVs as 32-bit floats.
- `UVCO` project section after the piece; skipped by older versions.
- Topology rebuilds (voxel remesh, dynamic detail, decimate, Subdivide,
  subdivision levels, Close holes, booleans…) drop UVs; the app shows a
  note once ("… has no UVs any more"), and Undo brings them back.

## Open questions

- Which subdivision rule for UV borders is the default: "keep corners" is
  what most texturing tools expect from Catmull–Clark UVs.
- Whether decimate can keep UVs (quadric decimation can carry them as extra
  attributes) in the first version.
- How UDIM tiles are shown, if at all, before there is a UV editor.

## Not included

- Unwrapping, UV editing and packing.
- Texture painting and baking inside OxyBrush.
