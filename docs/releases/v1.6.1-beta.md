## Changes in this release

**Preferences Dialog Layout & Geometry Fix**
- Fixed an issue where the settings scroll area inherited the parent's horizontal layout direction, causing General settings (layout presets, panel arrangements, and startup options) to be laid out horizontally in a single cut-off row.
- Ensured an explicit vertical layout inside the scroll area, restoring clean vertical stacking of all options and sections.
- Removed fixed viewport centering anchor (`anchor(CENTER_CENTER)`), restoring proper window title bar positioning, smooth dragging, and standard close button accessibility.
- Cleaned up tab navigation styling with dedicated selectable button items and tooltips.
