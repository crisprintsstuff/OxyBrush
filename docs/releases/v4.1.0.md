**OxyBrush 4.1.0** is the first minor release after the stable 4.0.0 line. It folds in the workflow features and fixes that landed on `main` after 4.0.0 — Scale cover Phase 2, Split view, Also paint, continuous orbit pitch, OxySpheres quad Resolution/Blend, Poly Edit Select with Ellipse, the new app icon, and wireframe on the Add Primitive preview.

## Highlights since 4.0.0

- **Scale cover Phase 2.** **Flow** orientation follows the piece's longest bounds axis; scatter can stay inside a **mask** or **face group**; **Types by face group** applies several plate kinds in one step (`INS3`). [RFC 0046](https://github.com/crisprintsstuff/OxyBrush/blob/main/docs/rfcs/0046-scale-cover.md)
- **Split view.** View > Split view: Off, Left / right, or Top / bottom. Each pane has its own camera; click a pane to sculpt or orbit there; drag the divider to resize. [RFC 0054](https://github.com/crisprintsstuff/OxyBrush/blob/main/docs/rfcs/0054-split-view.md)
- **Also paint.** On sculpt brushes (Draw, Clay, …), lay the Paint color under each dab while you sculpt. Color Jitter and the color picker apply; Alt still carves. [RFC 0052](https://github.com/crisprintsstuff/OxyBrush/blob/main/docs/rfcs/0052-also-paint.md)
- **MCP `set_geometry`.** Python / local agents can write vertex colors, positions and mask from an `OXYG` file as one undo step. [#555](https://github.com/crisprintsstuff/OxyBrush/issues/555), [RFC 0053](https://github.com/crisprintsstuff/OxyBrush/blob/main/docs/rfcs/0053-mcp-geometry-write.md)
- **Orbit past ±90°.** Dragging the view up or down tumbles through the poles and can go upside down.
- **OxySpheres quad Resolution and Blend.** Same sliders as voxel skin: Resolution densifies rings on long limbs; Blend softens three-way joins. [#477](https://github.com/crisprintsstuff/OxyBrush/issues/477), [RFC 0038](https://github.com/crisprintsstuff/OxyBrush/blob/main/docs/rfcs/0038-oxyspheres-quad-base-mesh.md)
- **Poly Edit Select.** The area row is labeled **Select** (was Pick) and offers **Ellipse** beside Click, Box and Lasso; hold **Shift** on Ellipse for a circle. Live outline while dragging. [RFC 0035](https://github.com/crisprintsstuff/OxyBrush/blob/main/docs/rfcs/0035-poly-edit-area-selection.md)
- **Project detail.** Mesh > Project detail snaps the active piece onto other visible pieces by closest point (background job; one undo). [#516](https://github.com/crisprintsstuff/OxyBrush/issues/516), [RFC 0051](https://github.com/crisprintsstuff/OxyBrush/blob/main/docs/rfcs/0051-detail-reproject.md)
- **Smooth preview outside Poly Edit**, **Show remesh density**, **Favorites** and preset editor, **alpha Roll / Tile / rotate jitter**, and **Scale cover** Phase 1 (Dino mode).
- **App icon.** Window, taskbar, installer and Flatpak icons use the new cyan/magenta circuit-brush mark.
- **Wireframe on Add Primitive preview.** Divisions show while adjusting + Add / Insert Primitive without the global wireframe. [#568](https://github.com/crisprintsstuff/OxyBrush/issues/568)

Also in this train: Accumulate defaults on for clay brushes, document tabs labeled Projects, movable Recipe Box, OxyRemesh faces slider to 100 000, OxyRemesh refusing fragmented shard extract ([#551](https://github.com/crisprintsstuff/OxyBrush/issues/551)), OxySpheres Make mesh status feedback, and Poly Edit pick restored on undo.

## Project files

Projects from 4.0.0 open unchanged. New optional sections (including `INS3` for scatter-on-mask/group) remain skippable for older readers; older builds keep legacy placement via `INST`.

## Known limitations

- macOS is not notarized (first launch needs **Open Anyway**).
- Pen pressure on Windows Ink and many Linux tablets still needs more tester confirmation.
- Dynamic detail is smoothest below a few hundred thousand triangles.
- OxyRemesh still refuses some extracts that would produce floating shards; use Voxel remesh / Ctrl+R meanwhile ([#551](https://github.com/crisprintsstuff/OxyBrush/issues/551)).
- Scale cover Phase 3 (fitted plates, vertex-color types, Noise underlay) remains open.
