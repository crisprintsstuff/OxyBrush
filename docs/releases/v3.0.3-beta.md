**OxyBrush 3.0.3-beta** makes **primitives parametric and low-poly by default**, adds a **Tube brush** that builds tubes into the piece you're sculpting, **`.oxyaddon` packages** for in-app and Python plugins, and navigation that feels more like other sculpting apps: **F frames the active piece**, and the **zoom direction can be flipped**. It's still a beta: please [report issues](https://github.com/crisprintsstuff/OxyBrush/issues/new?template=bug_report.yml) (or use **Help > Report a bug…** in the app).

**First launch:**
- **macOS:** open the `.dmg`, drag OxyBrush to Applications, and open it. If macOS shows an untrusted developer warning, go to **System Settings > Privacy & Security**, scroll down and click **Open Anyway**.
- **Windows:** SmartScreen warns about an unknown publisher: click **More info**, then **Run anyway**.

## New

- **Tube brush:** **Tube** in the brush shelf, next to Insert Primitive.
  - Drag a path to draw a tube, then shape it the same way as the tube tool.
  - **Accept** adds it **into the active piece**, in a face group of its own.
  - A checkbox in the Tube window makes it a new piece instead.
- **Add-on packages (`.oxyaddon`):** one file that installs a plugin, either an in-app (WebAssembly) plugin or a **Python** plugin.
  - Install with **Settings > Plugins > Install add-on…**, or by opening the file.
  - Create one with `oxybrush-cli addon pack <folder> <file.oxyaddon>`.
- **Plugin API 2:** in-app plugins can also set the **mask** and **vertex colors**, **add new pieces**, and read normals and colors. Their commands appear in the **command palette**. Plugins written for API 1 keep working.

## Changed

- **Parametric primitives:** **Pieces > + Add** opens a window with the shape's parameters and a live preview.
  - Parameters cover size, height, segments, rows, caps and tube radius.
  - Shapes are **low-poly by default**: a cube is 8 vertices, a cylinder 24 segments.
  - **Even triangles (voxel remesh)** is an opt-in checkbox when you want a sculpt-ready mesh.
- **F frames the active piece**, centred on it; **Alt+F** frames everything.
- **Zoom direction:** **Settings > Keymap > Zoom direction** can invert zoom drags and the mouse wheel. In the **Right-drag orbit** preset, Ctrl+right-drag **down** now zooms in, as in ZBrush.

See the [changelog](https://github.com/crisprintsstuff/OxyBrush/blob/main/CHANGELOG.md) for details.

Unchanged from 3.0.2-beta: projects open in either version.

## Known limitations

- **Not yet tried by testers:** everything above. The Blender bridge add-on from 3.0.2-beta still hasn't been run inside Blender either; please tell us how it behaves.
- **Tube brush:** the tube is added as its own shell in the piece; voxel remesh fuses it into the surface.
- **Primitives:** parameters can't be changed after Accept; the sphere is an icosphere.
- **Add-ons:** there's no Uninstall button yet (delete the add-on's folder from **Open plugins folder**), and add-ons are not signed.
- macOS is not notarized; pen pressure and touch gestures are untested on many tablets.
- Vertex color isn't exported yet; remesh, decimate and merge remove it.
