## Changes in this release

### Screen Curve Cutting Tools (Phase 4)
- **ClipCurve (Flatten along plane)**: Projects geometry from the shaded side of the screen-space line directly onto the clipping plane, maintaining a closed silhouette.
- **TrimCurve (Geometry cut & watertight cap)**: Slices off mesh geometry on the shaded side of the cut line and constructs a watertight, planar triangle cap with clean topology.
- **SliceCurve (Polygroup bisection)**: Divides the mesh across the cutting plane without geometry loss, assigning distinct polygroups to the two halves for isolated selection and manipulation.
- **Screen-Space Curve Gestures**:
  - `Ctrl + Shift + Drag` to draw cutting line/curve.
  - Directional shadow gradient indicating which side of the geometry will be cut or flattened.
  - `Alt + Tap` to create sharp corner control points.
  - `Alt + Double-Tap` to create smooth Bézier curve points.
  - `Space + Drag` to translate the entire cut curve anywhere on screen before releasing to execute.
  - Full undo/redo integration with topology snapshots.

### ZBrush Classic UI Layout (Phase 5)
- **Optional Classic Docked Layout**: Switchable in **Preferences > Layout** (`UiLayout::ZBrushClassic`), preserving existing user layouts while providing a faithful classic workspace for ZBrush veterans.
- **Dual-Column Brush Shelf**: Displays brushes in a 2-column icon grid on the left shelf with spherical previews.
- **Classic Top Quick Controls**: Adaptive top toolbar displaying classic terminology: `Draw Size`, `Z Intensity`, `ZAdd`, and `ZSub`.

### Topology Diagnostics & Mesh Cleanup (Phase 5)
- **Interactive Topology Diagnostics**: Accessible under `Mesh > Topology Diagnostics...` window.
- **2-Manifold Analysis**: Real-time evaluation of watertightness, boundary edges, non-manifold edges, and degenerate triangles.
- **One-Click Degenerate Cleanup**: Safely cleans collinear and zero-area triangles (`clean_degenerate_triangles`) with full undo history support.
