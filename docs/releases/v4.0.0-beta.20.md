**OxyBrush 4.0.0-beta.20** brings Autodesk FBX import, the new Sculptor dark slate theme with concentric clay sliders and sculpted icons, an upgraded hierarchical outliner with folders and search, and dynamic UI tint and intensity sliders. It's still a beta: please [report issues](https://github.com/crisprintsstuff/OxyBrush/issues/new?template=bug_report.yml) (or use **Help > Report a bug…** in the app), or talk about it on [Discord](https://discord.gg/Vfm7Km7xvG).

## New & Improved

- **Autodesk FBX Import** ([#367](https://github.com/crisprintsstuff/OxyBrush/pull/367)):
  - **Comprehensive format support**: Import 3D models and character assets saved in Autodesk FBX (`.fbx`), spanning modern FBX 7.x binary, ASCII FBX, and legacy FBX 5.8/6.x binary files.
  - **Multi-mesh hierarchy**: Imports all pieces in a scene with relative transforms, mesh normals, materials, and polygon triangulation in a single atomic undo step.
- **Sculptor Theme & UI Redesign** ([#368](https://github.com/crisprintsstuff/OxyBrush/pull/368)):
  - **Sculptor theme**: A dedicated dark charcoal slate theme designed for focused sculpting sessions, featuring high-contrast panel cards and subtle border etching.
  - **Pill tracks & concentric sliders**: Smooth pill slider tracks paired with concentric circular clay thumbs that give tactile visual feedback.
  - **Sculpted silver-clay icons**: Custom 3D brush glyphs rendered in sculpted silver clay across the brush shelf.
- **Upgraded Pieces Tree-View Outliner** ([#369](https://github.com/crisprintsstuff/OxyBrush/pull/369)):
  - **Folder / group pieces**: Create empty folder pieces to organize subtools, limbs, clothing, and props into clean hierarchy groups.
  - **Interactive drag-and-drop parenting**: Drag any piece onto another to parent it, between pieces to reorder, or drop at the bottom to unparent.
  - **Outliner search filter**: Fast real-time name filtering in the Pieces panel to navigate complex multi-piece scenes with dozens of subtools.
  - **Multi-selection batch actions**: Select multiple pieces with Shift/Ctrl to toggle visibility, delete, duplicate, or parent in batch.
  - **Expand / Collapse all**: One-click chevron toggles to expand or fold the entire scene hierarchy at once.
- **UI Color, Hue & Intensity Customization** ([#371](https://github.com/crisprintsstuff/OxyBrush/pull/371)):
  - **Spectrum hue slider (`0.0° ..= 360.0°`)**: Slide continuously through the full 360-degree color wheel to tint the application chrome.
  - **Color intensity slider (`0% ..= 100%`)**: Adjust tint saturation on panels, windows, and controls using perceptual luminance weighting to preserve readability.
  - **UI brightness slider (`-50% ..= +50%`)**: Shift chrome lightness between deep OLED black and softer studio grey.
  - **Preset swatches & picker**: Quick one-click color swatches (Neutral, Slate, Ocean, Forest, Amber, Crimson, Purple), custom RGB picker popup, and Reset button.
  - **Session persistence**: All UI color preferences persist in settings across application launches.

See the [changelog](https://github.com/crisprintsstuff/OxyBrush/blob/main/CHANGELOG.md) for details.
