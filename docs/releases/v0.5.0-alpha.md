**OxyBrush 0.5.0-alpha** brings custom scripting, high-density performance enhancements, and extensive personalization to OxyBrush: write and run **Python plugins** with the new pure-Python SDK, sculpt with an on-machine **local AI agent** via Model Context Protocol (MCP), customize every shortcut with the **keymap editor**, navigate using **Blender/Maya mouse presets**, and enjoy vastly smoother sculpting on dense meshes with parallel acceleration and stroke budgeting. It's an alpha release: please [report issues](https://github.com/crisprintsstuff/OxyBrush/issues/new?template=bug_report.yml) or use **Help > Report a bug…** in the app.

## New in this release

**Python Plugin & Scripting System**
- **Pure Python SDK (`python/oxybrush`):** Script OxyBrush in Python 3 with zero external dependencies. Connects via loopback JSON-RPC MCP to inspect scenes, configure brushes, execute 3D strokes, manage topology (remesh, decimate, subdivide), and import/export assets.
- **In-App Plugins Menu:** Launch any Python script from a file dialog, run installed plugins with one click, open your plugins folder, and reload plugins on the fly.
- **Example Plugins (`examples/plugins/`):** Procedural spiral generator and scene topology inspector included out of the box.

**Performance Overhaul for Dense Meshes**
- **Stroke Coalescing & Dab Budget:** Adaptive dab pacing (`OXYBRUSH_DAB_BUDGET_MS`, default 10 ms) eliminates stroke lag and queuing during fast mouse sweeps on multi-million polygon models.
- **Parallel Geometry Processing:** Rayon-parallelized vertex dedup, atomic stamps, and adjacency derivation in `update_after_move`.
- **Parallel GPU Uploads:** Parallel vertex packing on rebuilds, 1024-triangle chunk granularity, contiguous dirty chunk batching, and zero-copy index buffers.

**Customization & Workflow**
- **Keymap Editor (Settings > Keymap):** Rebind any tool, view command, or sculpt modifier. Includes full conflict detection and one-click resets.
- **Mouse Navigation Presets:** Choose between standard OxyBrush and **MMB Orbit** (middle button orbit, Shift+MMB pan, Ctrl+MMB zoom) matching Blender and Maya workflows.
- **Autosave Control:** Toggle autosave off or set custom intervals down to 0 min in Settings.
- **Perspective Focal Length:** 35mm-equivalent camera focal length slider (15mm–200mm) with standard presets (18, 35, 50, 85, 135 mm).
- **Surface-Aligned Cursor:** Optional 3D cursor ring conforming to local surface normals.
- **Custom Viewport Backgrounds:** Soft studio gradients, flat backgrounds, and custom color pickers.
- **Contextual Tooltips:** Comprehensive explanation and shortcut on hover/touch-hold across every UI control.
- **Neutral Gray Theme:** Interface chrome updated to neutral gray for accurate color perception.
- **Local AI Agent (MCP):** Connect external AI assistants and tools locally over the Model Context Protocol (RFC 0003).

**Fixes**
- **Grab Across Symmetry:** Blended symmetry copies prevent seams from tearing open on the mirror plane.

See the [changelog](https://github.com/crisprintsstuff/OxyBrush/blob/main/CHANGELOG.md) for full details.

## Known limitations

- Python plugins require Python 3 to be installed on the host system.
- Vertex color isn't included in exports yet, and remesh/decimate remove it.
- Transform gizmo uses world axes only.
