## Changes in this release

**Native ZBrush File Import (.ztl and .zpr)**
- Native decoding of ZBrush Tool (`.ztl`) and Project (`.zpr`) files without external tools or dependencies.
- Subtools are extracted as individual pieces with preserved SubTool names, quad/triangle topologies, and polygroups / face groups.
- Decompresses RLE-encoded geometry streams, supporting modern IEEE 754 floats as well as primitive fixed-point vertex buffers.
- Correctly applies SubTool coordinate transformations (scale and translation matrices) into world space with proper outward normals.
- Direct integration into File > Open and File > Import menus and dialog filters.

**Customizable Wireframe Color**
- Choose custom wireframe colors to contrast with any matcap material or theme.
- Interactive color picker available in the View menu under `View > Wireframe` and via the Command Palette (`Ctrl+P`).
- Persists across sessions in `settings.txt`.

**Window Focus Loss & Synthetic Input Fixes (Issue #54)**
- Fixed an issue where switching windows (e.g., via Alt+Tab or clicking outside the window) caused the viewport camera projection to toggle between perspective and orthographic mode.
- Correctly handles window focus transitions by surrendering keyboard focus and clearing active pointer interactions, while filtering synthetic OS keyboard events.

**Hover Tooltip Responsiveness**
- Tooltips across the shelf, toolbar, and menus now appear reliably and quickly with reduced hover delay and grace timing.
