**OxyBrush 4.0.0-beta.21** completes multi-tab project support (session restore, multi-tab crash recovery, cross-tab piece copy/paste with living strokes, and tab isolation for plugins, the local AI agent, and app links), adds the Parts Bin library for reusable sculpting details and curve path editing for Living Strokes, improves grab-family symmetry near the mirror plane, adds outliner range selection and batch parenting, and moves theme controls into **Preferences > Appearance**. It's still a beta: please [report issues](https://github.com/crisprintsstuff/OxyBrush/issues/new?template=bug_report.yml) (or use **Help > Report a bug…** in the app), or talk about it on [Discord](https://discord.gg/Vfm7Km7xvG).

## New & Improved

- **Tabbed Projects (RFC 0027, Phases 1–5)** ([#381](https://github.com/crisprintsstuff/OxyBrush/pull/381), [#382](https://github.com/crisprintsstuff/OxyBrush/pull/382), [#383](https://github.com/crisprintsstuff/OxyBrush/pull/383), [#385](https://github.com/crisprintsstuff/OxyBrush/pull/385)):
  - **Multi-document tab bar**: Open multiple `.oxb` projects in one window with per-tab document state (mesh, undo history, camera, tools in progress, alphas, and living strokes), disambiguated duplicate filenames, unsaved change dots, background job badges, drag-and-drop tab reordering, overflow menu (`»`), and multi-file CLI / file-drop opening.
  - **Tab navigation & lifecycle**: Added shortcuts (`Ctrl+T` new tab, `Ctrl+W` close tab, `Ctrl+Tab` / `Ctrl+Shift+Tab` cycle, `Ctrl+1–9` jump, `Ctrl+Shift+T` reopen closed project), multi-tab quit dialog with **Save all**, and per-tab **File > Revert**. (`Group from mask` moved to `Ctrl+Shift+W`, with automatic migration for existing keymaps.)
  - **Session restore & multi-tab crash recovery**: Clean quits remember open saved tabs and restore them on launch (toggleable under **Preferences > General**). Per-tab autosaves track their source path via sibling `.oxb.path` sidecars, win over session restore without opening duplicates, and offer per-tab **Recover / Discard**, **Recover all**, **Discard all**, and **Later**. **Recent files** focuses already-open tabs without prompting to discard.
  - **Cross-tab Copy & Paste piece (`Ctrl+C` / `Ctrl+V`)**: Copy selected pieces with hierarchy, mesh attributes, multires, materials, and living strokes across tabs as one undo step (baking living strokes with a status note if the destination budget is full).
  - **Plugin, MCP & Bridge isolation + shared undo budget**: WebAssembly previews/jobs, Python plugin listeners (`⏳` indicator on the origin tab), MCP `open`, and external app link tabs (`⇄ `) stay isolated to their tab, while a shared 4 GiB undo cap compresses inactive tabs first and evicts least-recently-used inactive history.
- **Grab-family symmetry blending fix** ([#384](https://github.com/crisprintsstuff/OxyBrush/pull/384)):
  - Overlapping symmetry copies on **Grab**, **Topological Move**, **Kelvin Grab / Twist / Scale**, and **Snake Hook** now sum their contributions and softly cap at one drag, eliminating the valley or ridge that previously formed when pulling geometry near the mirror plane.
- **Parts Bin library & portable details (RFC 0026, RFC 0025 Phases 4–5)** ([#379](https://github.com/crisprintsstuff/OxyBrush/pull/379)):
  - Save editable Living Stroke details to `.oxydetail` files, browse and filter them in the viewport bottom Parts Bin drawer, drag them onto a surface with single, mirrored-pair, or centered symmetry-plane placement options, and persist placed details across `.oxb` saves via the backward-compatible `PART` section.
- **Living Strokes: Edit stroke path as a curve (RFC 0025 Phase 3)** ([#377](https://github.com/crisprintsstuff/OxyBrush/pull/377)):
  - Reshape an existing living stroke's trajectory using interactive Catmull–Rom surface handles (`Edit path`), updating the sculpt live with full undo/redo support.
- **Pieces outliner range selection & batch parenting** ([#380](https://github.com/crisprintsstuff/OxyBrush/pull/380)):
  - Select ranges of pieces with `Shift+click` or toggle multi-selections with `Ctrl/Cmd+click`, then parent or unparent all selected pieces at once via drag-and-drop or the right-click context menu in a single undo step.
- **Unified Preferences > Appearance tab** ([#376](https://github.com/crisprintsstuff/OxyBrush/pull/376)):
  - Consolidated the standalone Theme window directly into **Preferences > Appearance**.

See the [changelog](https://github.com/crisprintsstuff/OxyBrush/blob/main/CHANGELOG.md) for details.

## Project files

No breaking changes to `.oxb` project files. Placed Parts Bin metadata uses the skippable `PART` section (ignored cleanly by older versions), and per-tab autosave source tracking uses sibling `.oxb.path` sidecars alongside autosave files.
