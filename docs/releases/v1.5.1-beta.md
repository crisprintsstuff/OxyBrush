**First launch:**

- **Windows:** SmartScreen warns about an unknown publisher: click **More info**, then **Run anyway**.

## Changes in this release

**Dedicated Theme & Appearance and Wireframe Settings Windows**
- Color pickers now open in dedicated, non-modal floating windows so they stay open while picking colors without being dismissed by menu dropdown closures.
- Accessible via `Settings > Theme & Appearance…`, `View > Wireframe settings…`, and Command Palette (`Ctrl+K`).
- Right-clicking the wireframe toggle button in the viewport view strip directly opens the wireframe settings window.

**Clickable Color Swatches & Quick Presets**
- Color swatches for accent color presets (`Terracotta`, `Cyan`, `Emerald`, `Amber`, `Crimson`, `Violet`, `Custom`) are now directly clickable.
- Wireframe settings include instant one-click color preset swatches (`Dark Slate`, `Light Gray`, `Terracotta`, `Electric Cyan`, `Emerald Mint`, `Golden Amber`) alongside full custom RGB/HSV controls and reset buttons.
