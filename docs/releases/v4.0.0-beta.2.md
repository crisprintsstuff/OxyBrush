**OxyBrush 4.0.0-beta.2** lets you **pin points in the retopology tool** so relaxing leaves them in place, lets you **drag the axis gizmo to orbit**, and fixes **opening files**: a double-clicked project no longer opens behind the Home window, and on macOS project files show the OxyBrush icon. It's still a beta: please [report issues](https://github.com/crisprintsstuff/OxyBrush/issues/new?template=bug_report.yml) (or use **Help > Report a bug…** in the app).

**First launch:**
- **macOS:** open the `.dmg`, drag OxyBrush to Applications, and open it from there. If macOS shows an untrusted developer warning, go to **System Settings > Privacy & Security**, scroll down and click **Open Anyway**.
- **Windows:** SmartScreen warns about an unknown publisher: click **More info**, then **Run anyway**.

## New

- **Pin points in the retopology tool.** Alt+click a point, edge or face to pin its points; with **Mirror across X** on, their mirror images are pinned too. **Shift+drag** relax leaves pinned points where they are, and you can still drag them by hand. Pinned points show as small squares in your accent colour. Alt+click again, or **Unpin all** in the Retopology window, frees them. Pinning is an undo step, and pins are saved with the project.
- **Drag the axis gizmo to orbit.** Drag anywhere on the axis gizmo at the top right of the viewport to turn the view freely, as in other 3D apps (hold Shift to step by 45°). Clicking an axis end still snaps to that side.

## Fixed

- **Opening a file no longer leaves the Home window on top.** With **Show at startup** on, a project you double-clicked (or opened with Open With, or dropped on the window) opened behind the Home window. Opening a file now closes it.
- **macOS: project files showed a "?" icon.** When macOS had missed OxyBrush's file types (for example after opening it first from the disk image), Finder showed `.oxb` files with a generic "?" icon. OxyBrush now registers itself with macOS each time it starts from Applications. Open it once from Applications after updating; Finder may take a moment, or a restart (`killall Finder`), to redraw icons it has already shown.

See the [changelog](https://github.com/crisprintsstuff/OxyBrush/blob/main/CHANGELOG.md) for details.

## Project files

Projects from 4.0.0-beta.1 open unchanged. Pinned retopology points are saved in a new section; older versions skip it and open the project with nothing pinned.

## Known limitations

- **Not yet tried by testers:** everything above. The macOS icon fix in particular needs confirming on a real Mac.
- **Alphas carry over between projects** in one session: alphas from a project you closed stay in the list and are saved with the next project too.
- **Import scaling** goes by size alone, so an import that really is meant to be 10× the scene gets scaled too: press Undo once to keep its original size.
- The box and lasso **hide/show** tools don't follow symmetry yet (masking does).
- **Dynamic detail** is smooth up to a few hundred thousand triangles and lags behind the brush around a million.
- The Blender bridge add-on still hasn't been run inside Blender.
- macOS is not notarized; pen pressure and touch gestures are untested on many tablets.
