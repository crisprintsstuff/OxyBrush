**OxyBrush 4.0.0-beta.6** answers two tester requests: **undo on one piece** without touching the others, and turning **a stroke into a curve**. It's still a beta: please [report issues](https://github.com/crisprintsstuff/OxyBrush/issues/new?template=bug_report.yml) (or use **Help > Report a bug…** in the app), or talk about it on [Discord](https://discord.gg/Vfm7Km7xvG).

## New

- **Undo on this piece** (**Ctrl+Alt+Z**, redo **Ctrl+Alt+Shift+Z**, also in the **Edit** menu). It takes back the last change to the active piece only, even if you've changed other pieces since; their changes stay. To make plain **Ctrl+Z** work this way, turn on **Preferences > General > Undo works on the active piece**; **Edit > Undo in whole scene** then does the usual undo. The **History** section can show only the active piece's changes.

  A change that touched several pieces at once (Join, Merge, Split…) can only be undone this way when nothing came after it; the status bar tells you when to use whole-scene undo instead.
- **Edit > Last stroke:** right after a Freehand stroke, reopen it as an **editable curve** with the same brush (drag its points, then press Enter), or use its path as a **Curve Move curve** or a **tube path**. The path lands where you drew it even if you've turned the view since. **Edit as curve** can also be given a key in the keymap.

See the [changelog](https://github.com/crisprintsstuff/OxyBrush/blob/main/CHANGELOG.md) for details.

## Known limitations

- Only the most recent Freehand stroke can be reopened, and only while it's still the newest change on its piece. Reopening any earlier stroke is planned as [Living strokes](https://github.com/crisprintsstuff/OxyBrush/blob/main/docs/rfcs/0017-living-strokes.md).
- Pieces created by Join, Duplicate or Split can't have their creation undone per piece; use whole-scene undo.
