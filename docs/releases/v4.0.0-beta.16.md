**OxyBrush 4.0.0-beta.16** lets **Living strokes remember what was drawn**, so a stroke can be **sculpted again with new settings**. **Edit…** changes its brush, Raise or Carve, size, strength, falloff, alpha or spacing. **View > Shading > Hard edge angle** sets how sharp a corner must be before those faces shade flat. It's still a beta: please [report issues](https://github.com/crisprintsstuff/OxyBrush/issues/new?template=bug_report.yml) (or use **Help > Report a bug…** in the app), or talk about it on [Discord](https://discord.gg/Vfm7Km7xvG).

## New

- **Living strokes remember what was drawn** ([RFC 0025](https://github.com/crisprintsstuff/OxyBrush/blob/main/docs/rfcs/0025-editable-and-portable-strokes.md), [#289](https://github.com/crisprintsstuff/OxyBrush/pull/289), [#290](https://github.com/crisprintsstuff/OxyBrush/pull/290)). With Living strokes on, each brush stroke also keeps its path, pressure and brush settings, and running them again makes exactly the same stroke. Saved with the project in a new optional `STRI` section. Curve strokes, stamps, lines and a freehand stroke you keep instead of editing as a curve are remembered, including a captured or imported alpha after you save and open the project. A captured alpha is matched by a hash of its pixels, so it still applies after the project is reopened. Strokes made with dynamic detail on, Curve Move, and whole-piece tools (Deform, the gizmo) aren't.
- **Edit a stroke's settings** ([#291](https://github.com/crisprintsstuff/OxyBrush/pull/291)). In the Strokes panel, **Edit…** (or double-click a stroke) opens its brush, Raise or Carve, size, strength, falloff, alpha and spacing. Changing one sculpts that stroke again; strokes made after it stay as they were. A slider shows a lighter preview while you drag and applies the full stroke when you let go. Each change is an undo step. Esc puts the stroke back as it was when you opened Edit. A stroke that can't be edited says why.

## Changed

- **Hard edge angle** ([#292](https://github.com/crisprintsstuff/OxyBrush/pull/292), View > Shading). How sharp a corner must be before the faces meeting there shade flat is now a slider, from 0° to 180°. The default is **40°**: a six-sided cylinder (faces 60° apart) and an eight-sided one (45°) shade flat along their length, and nine or more sides stay smooth. **180°** is shown as Off and keeps every edge smooth. It is remembered with the other view settings and is not saved in the project; there is no undo.

See the [changelog](https://github.com/crisprintsstuff/OxyBrush/blob/main/CHANGELOG.md) for details.

## Project files

Projects from earlier betas open unchanged. This beta adds one new project section. Older versions open files that have it as follows:

| New section | What it saves | In older versions |
|---|---|---|
| `STRI` | What was drawn for each living stroke (path, pressure, brush settings) | The section is skipped and the strokes stay as they look |
