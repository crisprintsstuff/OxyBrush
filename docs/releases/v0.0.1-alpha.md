**First public alpha of OxyBrush**, an open-source digital sculpting app written in Rust. Expect rough edges; please [report issues](https://github.com/crisprintsstuff/OxyBrush/issues).

## What's in it

- **Sculpting:** 12 brushes (Draw, Clay, Clay Strips, Smooth, Inflate, Flatten, Pinch, Crease, Layer, Grab, Snake Hook, Mask) with falloff, spacing, auto-smooth and pen-pressure options
- **Symmetry:** X/Y/Z mirror and radial (up to 64 copies)
- **Pieces:** several meshes per document — add, duplicate, mirror, delete, rename, hide, solo
- **Topology:** voxel remesh, merge visible pieces, decimation, subdivision
- **Face groups & visibility:** group by visible/mask/islands, isolate with Ctrl+Shift+click, delete hidden
- **Files:** `.oxb` projects with autosave every 2 minutes and crash recovery; OBJ/STL import and export
- **Undo/redo** for everything, plus UI scaling and a high-contrast theme

## Known limitations

- Tablet pressure is not yet confirmed on Windows Ink or Linux tablets
- Decimating very dense meshes is slow (~10 s for 1.3M triangles; runs in the background)
- Remesh resets mask and face groups; open surfaces remesh to a thin shell
- Settings are not remembered between sessions
- Not yet tested by people on real hardware — this release is how that starts
