**OxyBrush 0.5.2-alpha** fixes Python SDK discovery and provisions bundled plugins for release and standalone binary installations. It's an alpha release: please [report issues](https://github.com/crisprintsstuff/OxyBrush/issues/new?template=bug_report.yml) or use **Help > Report a bug…** in the app.

**First launch:**

- **Windows:** SmartScreen warns about an unknown publisher: click **More info**, then **Run anyway**.

## Changes in this release

**Embedded Python SDK Auto-Provisioning**
- **Zero-Configuration `oxybrush` Module:** Fixed `ModuleNotFoundError: No module named 'oxybrush'` on Windows and standalone release packages. The pure-Python SDK is now embedded directly in the OxyBrush executable and automatically provisioned into your local application data directory (`%LOCALAPPDATA%\OxyBrush\python` on Windows, `~/.local/share/oxybrush/python` on Linux, and `~/Library/Application Support/oxybrush/python` on macOS).
- **Auto-Provisioned Bundled Example Plugins:** When OxyBrush launches, it now automatically provisions the bundled example scripts into your plugins folder (`%LOCALAPPDATA%\OxyBrush\plugins` on Windows):
  - `mesh_stats_reporter.py` (live mesh topology metrics on the status bar)
  - `mesh_stats.py` (piece inspection and bounding dimensions)
  - `spiral_generator.py` (procedural 3D sculpting stroke generation)
- **Standalone Terminal Fallback:** All example scripts now include a smart fallback that locates the provisioned OxyBrush SDK automatically, allowing scripts to be run directly via `python <script>.py` from the command line without setting `PYTHONPATH` manually.

See the [changelog](https://github.com/crisprintsstuff/OxyBrush/blob/main/CHANGELOG.md) for full details.

## Known limitations

- Python plugins require Python 3 to be installed on the host system.
- Vertex color isn't included in exports yet, and remesh/decimate remove it.
- Transform gizmo uses world axes only.
