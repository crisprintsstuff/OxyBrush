## Fixes & Improvements

- **Inspector panel runaway width fix**:
  - Bound inspector panel width with `max_size` (capped at 45% of viewport width or 500pt), preventing feedback loops from expanding the panel across the screen in Standard and Touch layout presets.
  - Adjusted Pieces search filter width to properly subtract trailing buttons and item spacing.
- **Scrollable Pieces box & resizable divider**:
  - The Pieces outliner is now enclosed in a dedicated scrollable box that prevents runaway vertical growth when scenes contain dozens of pieces.
  - Added an interactive separator handle below the pieces list that can be dragged up or down to adjust the visible height (double-click to reset to default height).
- **Pieces outliner vector icons**:
  - Replaced missing Unicode font glyphs for Expand All, Collapse All, and fold/unfold chevrons with crisp, native vector icons (`ChevronDown`, `ChevronRight`, `ExpandAll`, `CollapseAll`).
  - Expand and Collapse buttons now render distinct, recognizable icons that never fail back to missing-glyph tofu bars.
- **Piece row right-click context menu**:
  - Fixed right-clicking piece rows by switching to `container_context_menu`, allowing users to open the context menu by right-clicking anywhere on a piece row.
  - Added a **Parent to…** submenu in the context menu to directly select a new parent piece without needing to drag.
- **Drag-and-drop parenting & unparenting**:
  - Moving a child piece to another parent by dragging now properly reparents the piece and maintains sibling order under the new parent.
  - Dragging a child piece out and dropping it adjacent to a root piece or onto the bottom drop strip cleanly unparents it to root level.
  - Dropping a piece onto a folded parent automatically unfolds it so the child is immediately visible.
  - Fixed premature drag-payload consumption so drag releases reliably trigger drop actions.
  - All parenting and reordering changes record as atomic, clean undo steps.

See the [changelog](https://github.com/crisprintsstuff/OxyBrush/blob/main/CHANGELOG.md) for details.
