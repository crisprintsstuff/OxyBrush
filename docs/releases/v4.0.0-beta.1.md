**OxyBrush 4.0.0-beta.1** makes **alphas captured from view** sharper (up to 4096 px), **saves them with your project**, and lets you **export any alpha** to edit in a 2D app. A new project started from **File > New > Cube** no longer has open seams. **OxyBrush now uses [semantic versioning](https://semver.org):** this is the first beta of 4.0.0 (it follows 3.0.8-beta). Betas count up as `4.0.0-beta.2`, `-beta.3`… until 4.0.0 is stable; the in-app updater orders them correctly. It's still a beta: please [report issues](https://github.com/crisprintsstuff/OxyBrush/issues/new?template=bug_report.yml) (or use **Help > Report a bug…** in the app).

**First launch:**
- **macOS:** open the `.dmg`, drag OxyBrush to Applications, and open it. If macOS shows an untrusted developer warning, go to **System Settings > Privacy & Security**, scroll down and click **Open Anyway**.
- **Windows:** SmartScreen warns about an unknown publisher: click **More info**, then **Run anyway**.

## New

- **Capture from view at up to 4096 px.** A size picker next to **Capture from view** offers 256, 512, 1024 (the new default; it used to be a fixed 256), 2048 and 4096 px, so captured alphas have smooth edges instead of blocky ones. Capturing is also much faster: 4096 px takes about a second on a 1.3-million-triangle sculpt, and the app stays responsive while it works. The size you pick is remembered.
- **Alphas are saved with the project.** Alphas you capture or load from an image are stored in the `.oxb` and come back when you open it. A new alpha counts as unsaved work, so you're asked to save before closing.
- **Export alpha…** (in the Alpha section, or the command palette) saves the selected alpha as a 16-bit grayscale PNG, to touch up in a 2D app and bring back with **Load image…**.

## Fixed

- **File > New > Cube made a cube with open seams.** Some points where two faces met weren't joined, so the cube shaded and sculpted badly along its edges; a cube added with **Pieces > Add** was fine. New cubes are now closed. A project already started from the broken cube keeps its seams; a voxel remesh repairs them.

See the [changelog](https://github.com/crisprintsstuff/OxyBrush/blob/main/CHANGELOG.md) for details.

## Project files

Projects from 3.0.8-beta open unchanged. Alphas are saved in a new section; older versions skip it and open the project without them.

## Known limitations

- **Not yet tried by testers:** everything above. A 4096 px alpha adds up to about 32 MB to a project before compression; how much it compresses depends on the image.
- **Alphas carry over between projects** in one session: alphas from a project you closed stay in the list and are saved with the next project too.
- **macOS shows a "?"** instead of the OxyBrush icon for some testers. On a clean macOS 26 machine the app and `.oxb` files show the right icon, so this is most likely macOS's icon cache: move OxyBrush to **Applications**, eject the disk image, remove old Dock entries and open it from Applications; if needed, log out and back in.
- **Import scaling** goes by size alone, so an import that really is meant to be 10× the scene gets scaled too: press Undo once to keep its original size.
- The box and lasso **hide/show** tools don't follow symmetry yet (masking does).
- **Dynamic detail** is smooth up to a few hundred thousand triangles and lags behind the brush around a million.
- The Blender bridge add-on still hasn't been run inside Blender.
- macOS is not notarized; pen pressure and touch gestures are untested on many tablets.
