**OxyBrush 4.0.0** is the first stable release. It leaves the long `4.0.0-beta.*` line behind and ships the sculpting, remesh, retopology, and workflow tools built during the beta on Windows, Linux, and macOS.

## Highlights since beta.24.7

- **Surface Noise.** Tools > Surface Noise… displaces the piece along normals with scale, strength, octaves, seed, and Smooth / Turbulent / Cellular patterns. Live preview; Apply is one undo step. [#541](https://github.com/crisprintsstuff/OxyBrush/issues/541), [RFC 0045](https://github.com/crisprintsstuff/OxyBrush/blob/main/docs/rfcs/0045-surface-noise.md)
- **OxyRemesh.** Field-aligned pure-quad remesh (Instant Meshes research, pure Rust), with attribute carry-over, adaptivity/anisotropy, last-stroke guide, and mask singularity attractor. [#529](https://github.com/crisprintsstuff/OxyBrush/issues/529), [RFC 0044](https://github.com/crisprintsstuff/OxyBrush/blob/main/docs/rfcs/0044-auto-retopology.md)
- **Amplify brush.** Height contrast relative to the dab plane; Alt softens it. [#519](https://github.com/crisprintsstuff/OxyBrush/issues/519)
- **Scene Project brush.** Project onto other visible pieces; Alt uses the surface normal. [#295](https://github.com/crisprintsstuff/OxyBrush/issues/295)
- **Cutter shapes** for Plane Clip, Line Split and Cut Away (curve, rectangle, lasso, circle, ellipse). [#492](https://github.com/crisprintsstuff/OxyBrush/issues/492)
- **Color Filter** for whole-piece vertex color. [#489](https://github.com/crisprintsstuff/OxyBrush/issues/489)
- **Poly Edit Box / Lasso pick**, rebuild lower subdivision level, replay last stroke, **3MF** export, and full reference **Back / Left / Bottom** planes.

Also in this train: remembered X-ray scope, new banner and app icon, focal shift in the Size/Strength bar, scrollable Poly Edit window, and paint strength that matches the slider without dab stacking.

## From the beta

4.0.0 includes the beta.24.x work already shipped: reference placement and landmark alignment, viewport X-ray, orthographic grids, Pieces isolation, Paint Color Jitter, Kelvin brush response, OxySpheres, Retopology on existing meshes, Living strokes / Recipe Box, tabbed projects, Poly Edit Knife, and the rest of the beta line. See earlier [release notes](https://github.com/crisprintsstuff/OxyBrush/blob/main/docs/releases/) and the [changelog](https://github.com/crisprintsstuff/OxyBrush/blob/main/CHANGELOG.md).

## Versioning

After this release, fixes bump **PATCH** (`4.0.x`), new features bump **MINOR** (`4.y.0`, with optional `-beta.N` previews), and breaking changes (for example an `.oxb` change older versions cannot read) bump **MAJOR**.

## Project files

Projects from `4.0.0-beta.*` open unchanged. Newer optional sections (including Surface Noise workflow data that is not stored as its own section — noise is baked geometry) remain skippable for older readers where applicable.

## Known limitations

- macOS is not notarized (first launch needs **Open Anyway**).
- Pen pressure on Windows Ink and many Linux tablets still needs more tester confirmation.
- Dynamic detail is smoothest below a few hundred thousand triangles.
- Scale cover / “Dino mode” is design-only ([RFC 0046](https://github.com/crisprintsstuff/OxyBrush/blob/main/docs/rfcs/0046-scale-cover.md)); not in this build.
