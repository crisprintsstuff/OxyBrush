**OxyBrush 4.0.0-beta.17** makes it easier to start from nothing, import a batch of models, and edit low-poly geometry. It also brings a more reliable resize experience, adjusted brush defaults and fixes for symmetry and Poly Edit. It's still a beta: please [report issues](https://github.com/crisprintsstuff/OxyBrush/issues/new?template=bug_report.yml) (or use **Help > Report a bug…** in the app), or talk about it on [Discord](https://discord.gg/Vfm7Km7xvG).

## New

- **Start with an empty scene** ([#318](https://github.com/crisprintsstuff/OxyBrush/pull/318)) from File > New or **Empty** in the welcome window. Build from scratch with Insert Primitive, + Add or Import. Empty scenes save and reopen normally.
- **Import several files at once** ([#319](https://github.com/crisprintsstuff/OxyBrush/pull/319)). Select multiple files in the Import dialog or drop a batch onto the window. Every object becomes a piece; a readable batch is one undo step, and fitting it to the scene uses one shared scale factor to preserve the files' relative sizes. Large batches run in the background.
- **Extrude Poly Edit faces along the gizmo** ([#317](https://github.com/crisprintsstuff/OxyBrush/pull/317)). In the Extrude section, **Along** can use **Normals** (the existing behavior) or **Gizmo**. With the gizmo shown, a face drag moves along its matching axis; each face's cap moves along that same axis. Mirror across X and Each face on its own still work.
- **Give the masked area its own face group** ([#316](https://github.com/crisprintsstuff/OxyBrush/pull/316)). When Edge loop at mask border is on, the visible triangles inside the mask can now be isolated as a group together with the new loop.
- **Choose an export format** ([#313](https://github.com/crisprintsstuff/OxyBrush/pull/313)) from File > Export type, including on macOS, where the save panel doesn't offer a format list. A filename extension you type still wins.

## Changed and fixed

- **More stable window resizing** ([#306](https://github.com/crisprintsstuff/OxyBrush/pull/306)) reduces UI warbling by synchronizing layout with the current size and coalescing intermediate surface updates.
- **Brush defaults** ([#307](https://github.com/crisprintsstuff/OxyBrush/pull/307)): Front faces only is off; Grab, Snake Hook, Topological Move, Kelvin movement brushes and Curve Move start at strength 0.5.
- **Crease and Sharp Crease** no longer leave a ridge on the mirror plane ([#309](https://github.com/crisprintsstuff/OxyBrush/pull/309)). **Kelvin Grab** keeps its elastic effect on ordinary pulls without bringing back long-pull creases ([#310](https://github.com/crisprintsstuff/OxyBrush/pull/310)).
- **Poly Edit** clears a picked element when you click empty space; dragging there still orbits without clearing it ([#312](https://github.com/crisprintsstuff/OxyBrush/pull/312)).
- **Group by islands** respects hidden faces, keeping visible islands separate when hidden faces connect them ([#314](https://github.com/crisprintsstuff/OxyBrush/pull/314)).
- **Planning:** RFC 0026 (Parts Bin) is accepted; RFC 0027 (tabbed projects) is a draft. Neither feature is implemented yet.

See the [changelog](https://github.com/crisprintsstuff/OxyBrush/blob/main/CHANGELOG.md) for details.

## Project files

Existing non-empty projects continue to open as before. Empty scenes are now valid `.oxb` documents; older OxyBrush betas may report an empty-scene file as damaged because they require at least one piece.
