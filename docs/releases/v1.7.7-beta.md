## Changes in this release

### Viewport & Frame Loop Optimization ($O(1)$ Quad Metric Caching)
- **Zero-Cost Status Bar:** Resolved an issue where `quad_and_triangle_counts()` was re-evaluating the entire mesh with heavy `HashMap` edge lookups on every single frame, burning 60–300ms per frame on 500k+ polygon sculpts. Metrics and quad diagonals are now lazily computed once and cached on `Mesh` with `OnceLock`, dropping per-frame status overhead to $0\,\text{ns}$.
- **Fast GPU Line Synchronization:** Wireframe line buffer building in `ViewportRenderer::sync` now takes a direct fast path for triangle meshes (direct edge pushes without hash table lookups) and reads cached diagonal references for quad meshes, eliminating multi-megabyte `HashSet` allocations during mesh rebuilds.
- **Parallel Edge Sorting:** Upgraded `find_quad_diagonals` with multi-threaded parallel sorting (`par_sort_unstable_by_key`) across CPU cores, cutting initial quad detection time in half.
- **Corner Angle Validation:** Added geometric angle checks so that subdivided equilateral triangles (like icospheres) are properly kept as triangles rather than falsely paired into diamonds.
