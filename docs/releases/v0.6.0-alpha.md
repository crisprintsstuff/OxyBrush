**OxyBrush 0.6.0-alpha** brings Pixar Regularized Kelvinlet sculpting brushes for elastodynamic volume-preserving deformation and hardware-accelerated real-time wireframe overlay. ## Changes in this release

**Pixar Regularized Kelvinlet Sculpting Brushes**
- Based on *Regularized Kelvinlets: Sculpting Brushes based on Fundamental Solutions of Elasticity* (Fernando de Goes & Doug L. James, SIGGRAPH 2017).
- **Kelvin Grab:** A volume-preserving elastodynamic grab brush with Poisson's ratio $\nu = 0.45$. Unlike simple geometric translation, pulling a surface outward causes lateral sides to pinch inward naturally, mimicking real physical clay, rubber, and skin tissue.
- **Kelvin Twist:** A pure rotational, divergence-free elastodynamic moment rotating the surface smoothly around the contact normal without tearing or singularity folds. Hold Alt to reverse twist direction.
- **Kelvin Scale:** An elastodynamic dipole expanding or contracting volume radially with natural decay.
- **60+ FPS Real-Time Interaction:** Precomputes the $3 \times 3$ linear elasticity tensor $\mathbf{K}(\mathbf{r})$ into symmetry-blended vertex matrices at stroke start, executing drag strokes with native hardware performance.
- Dedicated profile icons, preview spheres, presets, and guide topics.

**Real-Time Wireframe Overlay**
- High-performance line-list GPU overlay (`wireframe.wgsl`) over the shaded matcap mesh.
- Depth-biased (`constant: -2, slope_scale: -2.0`) and depth-tested to eliminate Z-fighting while maintaining crisp polygon edge outlines.
- Instant toggle via keyboard shortcut `Shift+W`, command palette, or the new isometric wireframe icon in the viewport view strip.
- View menu opacity slider (0.0 to 1.0) and settings persistence in `settings.txt`.

See the [changelog](https://github.com/crisprintsstuff/OxyBrush/blob/main/CHANGELOG.md) for full details.

## Known limitations

- Python plugins require Python 3 to be installed on the host system.
- Vertex color isn't included in exports yet, and remesh/decimate remove it.
- Transform gizmo uses world axes only.
