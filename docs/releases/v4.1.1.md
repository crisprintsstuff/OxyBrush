**OxyBrush 4.1.1** is a patch on the 4.1.0 line: inspector declutter (Focus layout, mode-aware panels) and a real fix for OxyRemesh extraction that was refusing too many jobs after 4.1.0.

## Highlights since 4.1.0

- **Inspector declutter.** Mode-aware settings panel (hides Brush/Stroke/Alpha during Poly Edit, Retopo, OxySpheres and Tube); Brush options and Alpha options collapse by default; Topology starts collapsed while sculpting; Project detail and Decimate live under Mesh. New **Focus** layout (Pieces + Brush only). Settings panel width is remembered. [#575](https://github.com/crisprintsstuff/OxyBrush/issues/575), [#580](https://github.com/crisprintsstuff/OxyBrush/pull/580)
- **Topology panel sections.** Voxel remesh and OxyRemesh each have their own section header; Shell/engine and OxyRemesh advanced knobs sit in collapsed option rows. [#575](https://github.com/crisprintsstuff/OxyBrush/issues/575), [#579](https://github.com/crisprintsstuff/OxyBrush/pull/579)
- **OxyRemesh extraction** ([#551](https://github.com/crisprintsstuff/OxyBrush/issues/551)). Face walks no longer burn dual edges on failed cycles. Collapse classification follows Instant Meshes §3.8 more closely; when a clear majority surface exists, floating islands are stripped instead of failing the whole job.

## Project files

Projects from 4.1.0 open unchanged. No new `.oxb` sections.

## Known limitations

- macOS is not notarized (first launch needs **Open Anyway**).
- Pen pressure on Windows Ink and many Linux tablets still needs more tester confirmation.
- Dynamic detail is smoothest below a few hundred thousand triangles.
- OxyRemesh can still fail some extracts; use Voxel remesh / Ctrl+R meanwhile ([#551](https://github.com/crisprintsstuff/OxyBrush/issues/551)).
- Scale cover Phase 3 (fitted plates, vertex-color types, Noise underlay) remains open.
