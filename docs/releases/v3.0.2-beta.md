**OxyBrush 3.0.2-beta** adds a **Blender bridge** (send meshes from Blender, sculpt, send them back), **in-app plugins** that run sandboxed inside OxyBrush, **Close holes**, and **alphas captured from the view**. It's still a beta: please [report issues](https://github.com/crisprintsstuff/OxyBrush/issues/new?template=bug_report.yml) (or use **Help > Report a bug…** in the app).

## New

- **Blender bridge:** the **OxyBrush Bridge** add-on for Blender 4.2+ (in [`integrations/blender`](https://github.com/crisprintsstuff/OxyBrush/tree/main/integrations/blender), GPL-3.0-or-later) adds **Object > Send to OxyBrush**.
  - The selected meshes open in OxyBrush, placed as they were, with a **Linked to Blender** badge.
  - **File > Send back to Blender**, or **Send back to Blender and close**, returns them.
  - Objects whose vertices you didn't add or remove keep their UVs, materials, modifiers and shape keys in Blender.
  - Pieces you made in OxyBrush arrive as new objects.
- **In-app plugins (WebAssembly):** plugins that run inside OxyBrush, with no Python and nothing to switch on.
  - **Settings > Plugins** lists them, and each has a panel with its sliders and buttons.
  - They can read meshes, change vertex positions (each change is an undo step) and draw in the viewport, but only what each one declares.
  - They have no access to files or the network, run in the background, and are stopped if they run too long.
  - An example plugin, **Squash**, is included.
- **Close holes** (Mesh menu): fills every opening in a piece with a smooth patch in a face group of its own, ready for 3D printing.
- **Capture alpha from view** (Alpha section): makes an alpha from a depth image of the model you see. Sculpt a detail, capture it, and stamp it anywhere.

See the [changelog](https://github.com/crisprintsstuff/OxyBrush/blob/main/CHANGELOG.md) for details.

## Known limitations

- **Not yet tried by testers:** all four new features. In particular, **the Blender add-on has not been run inside Blender yet**; please tell us how it behaves.
- **Blender bridge:** OBJ exchange only (no vertex colors or UVs from OxyBrush); sending again opens a second OxyBrush window; shape keys' own coordinates are not updated.
- **Plugins:** they can only change vertex positions so far, and plugin commands are not in the command palette yet.
- **Capture alpha:** a dense scene pauses the window for about a second; captured alphas are not kept after OxyBrush closes.
- **Close holes:** a jagged cut edge leaves slight ripples near the rim of the patch.
- macOS is not notarized; pen pressure and touch gestures are untested on many tablets.
- Vertex color isn't exported yet; remesh, decimate and merge remove it.
