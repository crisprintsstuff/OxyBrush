**OxyBrush 4.0.0-beta.22** adds theme mixing, updated window menus, Recipe Box organization, and more ways to place surface instances. It also improves the Blender bridge and keeps imported UVs and polygon structure through subdivision. Please [report issues](https://github.com/crisprintsstuff/OxyBrush/issues/new?template=bug_report.yml) or share feedback on [Discord](https://discord.gg/Vfm7Km7xvG).

## Interface

- **Mix themes.** Pick colors, controls, and shadows independently in **Preferences > Appearance > Themes > Mix**. For example, use Graphite colors, Sculptor controls, and Studio shadows. The mix is saved with your appearance settings. Floating windows now cover the Recipe Box and receive clicks over it. [#409](https://github.com/crisprintsstuff/OxyBrush/pull/409)
- **Windows and Linux.** The menus, project name, and window controls share one title bar, with tabs below it. **Preferences > General > Use system title bar** restores the system layout at the next start. [#407](https://github.com/crisprintsstuff/OxyBrush/pull/407)
- **macOS.** Menus move to the system menu bar, leaving tabs first in the window. The app and Window menus include Settings, Hide, Quit, Minimize, Zoom, and full screen. The shading sliders are available in a Shading window. Native Mac interaction still needs tester feedback. [#410](https://github.com/crisprintsstuff/OxyBrush/pull/410)

## Sculpting and mesh workflow

- **Recipe Box.** Click a slot to rename or categorize it, reorder it, pick a category variation, or delete it from the library. Recipes already placed on a model stay editable. [#404](https://github.com/crisprintsstuff/OxyBrush/pull/404)
- **Surface instances.** Copy onto the masked surface or evenly scatter copies across visible faces with adjustable spacing and a repeatable seed. Copies render even when their source mesh is hidden. [#404](https://github.com/crisprintsstuff/OxyBrush/pull/404)
- **UVs through subdivision.** Catmull–Clark and Loop preserve face-corner UVs, so seams and islands survive level switching, save and reopen, and OBJ/GLB export. [#403](https://github.com/crisprintsstuff/OxyBrush/pull/403)
- **Imported quads and n-gons.** OBJ and FBX keep the original polygons for the wireframe, quad subdivision, and export. Folded quads stay quads, and concave quads split along their inside diagonals. The Blender bridge also keeps incoming polygon structure. [#405](https://github.com/crisprintsstuff/OxyBrush/pull/405)

## Blender bridge

- **Upright models and window reuse.** Blender’s Z-up axes convert to OxyBrush’s Y-up axes on send and back again on return, including for new pieces. A running window reuses an untouched active tab and offers destination options when a tab already contains work. [#406](https://github.com/crisprintsstuff/OxyBrush/pull/406)
- **Shape keys and repeat returns.** Position-only returns move the Basis and preserve each shape key’s offset. Sending a new piece back again updates the Blender object that the bridge previously created. [#403](https://github.com/crisprintsstuff/OxyBrush/pull/403)

## Project files

This release adds optional `MRUV`, `POLY`, and `INS2` sections for subdivision UVs, original polygons, and the new instance placements. Earlier versions skip these sections and retain the active mesh. They can still read its active UVs and existing face, point, and group instance modes. Keep a project copy before resaving in an earlier beta.
