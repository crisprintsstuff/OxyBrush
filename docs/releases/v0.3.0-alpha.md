**OxyBrush 0.3.0-alpha** makes sculpted detail easier to see with **ambient occlusion and cavity shading**, and makes dense meshes faster: **subdivision level changes now run in the background**, and decimation is about twice as fast. It's still an alpha: please [report issues](https://github.com/crisprintsstuff/OxyBrush/issues/new?template=bug_report.yml) (or use **Help > Report a bug…** in the app).

**First launch:** the packages aren't signed with a paid developer certificate yet.

- **Windows:** SmartScreen warns about an unknown publisher: click **More info**, then **Run anyway**.

## New in this release

- **Viewport shading:** ambient occlusion darkens folds and the spaces between forms; cavity shading darkens creases and pores and lets edges catch the light, so fine detail and alpha stamps read clearly. On by default; switch it with the ball button in the view strip and set strengths in **View > Shading**.
- **Responsive with dense meshes:** adding or switching subdivision levels above 1M triangles runs in the background, so the window keeps responding (orbit and work on other pieces meanwhile). Switching to a 5M-triangle level is about 3× faster than in 0.2.
- **Faster decimation:** about twice as fast (1.3M → 130k triangles in ~6 s on our test machine).
- **Snappier small brushes,** and faster opening of large projects.
- **Fix:** strokes made on a piece while it was being remeshed or decimated were lost when the operation finished; that piece now waits until the operation is done.

See the [changelog](https://github.com/crisprintsstuff/OxyBrush/blob/main/CHANGELOG.md) for details.

**Tell us about your GPU:** the shading is new and has only been tested on a software renderer. If it looks wrong or slows things down, turn it off with the ball button and please [report it](https://github.com/crisprintsstuff/OxyBrush/issues/new?template=bug_report.yml) with your GPU (Help > Copy system info).

## Known limitations

- While a level change runs in the background, that piece can't be edited, deleted or saved until it finishes (the status bar shows progress).
- The shading only knows what's on screen, so it can change slightly at the viewport edges and around silhouettes.
- The Touch layout has no multi-touch gestures yet (pinch zoom, two-finger orbit) and hasn't been tried on real touchscreens or tablets.
- macOS is still untested on real Macs; pen pressure is still unverified on real tablets.
- Brush settings (radius, strength, falloff) aren't remembered between sessions yet.
