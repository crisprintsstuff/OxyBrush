## New

- **High-poly stability and performance**:
  - **Partitioned GPU rendering**: Draw calls and index buffers are split into bounded 1M-triangle partitions (`PARTITION_TRIANGLES = 1,048,576`), binding sub-slices of face color storage buffers. Meshes render without exceeding device storage buffer limits (`128 MB`), enabling smooth rendering of 200M–600M+ triangle sculpts without VRAM allocation failures.
  - **Compressed undo history**: Inactive stroke chunk snapshots and face attribute changes in undo/redo history are compressed with LZ4 (reducing memory footprint by 60%–99%), keeping RAM bounded during long high-poly sessions while keeping the active top stroke instant.
  - **Multires detail compaction**: Multiresolution levels with zero displacement no longer allocate empty displacement detail buffers, saving 1.2 GB – 4.8 GB RAM per subdivision level.
  - **VRAM culling**: Hidden pieces immediately release their vertex, index, and storage buffers from GPU VRAM, freeing gigabytes of video memory in dense multi-piece scenes.
  - **Driver crash prevention**: Wireframe overlay is safely gated to meshes with $\le 10\text{M}$ triangles to prevent multi-gigabyte line buffer driver crashes, and storage buffer allocations are clamped to hardware limits. Removed redundant mesh chunk index arrays, saving 800 MB RAM per 200M triangles.
- **Scene & Pieces workflow**:
  - **Reorder pieces by drag-and-drop** ([#297](https://github.com/crisprintsstuff/OxyBrush/issues/297)): Drag pieces in the Pieces list by their grip handle to rearrange their order in the scene.
  - **Join picked pieces** ([#297](https://github.com/crisprintsstuff/OxyBrush/issues/297), [#284](https://github.com/crisprintsstuff/OxyBrush/issues/284)): Ctrl/Cmd+click multiple pieces and click **Join picked** to combine them into one piece without remeshing.
  - **Isolate piece with Alt-click** ([#297](https://github.com/crisprintsstuff/OxyBrush/issues/297)): Alt-click a piece's eye icon to solo that piece; Alt-click again to restore all pieces.
- **Poly Edit gizmo axes and pivot** ([#324](https://github.com/crisprintsstuff/OxyBrush/issues/324)): Align transform gizmo axes to World, View, or selection Normal in the **Pivot & axes** menu. Alt+click to snap pivot to a vertex, edge, or face, and Alt+drag handles to reposition the gizmo.
- **Invert brush alphas** ([#339](https://github.com/crisprintsstuff/OxyBrush/issues/339)): Toggle **Invert alpha** to invert alpha values on brushes and living strokes with live thumbnail updates.
- **Stamp stroke smoothing** ([#342](https://github.com/crisprintsstuff/OxyBrush/issues/342)): Stamp stroke mode redraws once per frame instead of on every mouse event for smooth dragging.
- **Export file type picker** ([#300](https://github.com/crisprintsstuff/OxyBrush/issues/300), [#344](https://github.com/crisprintsstuff/OxyBrush/issues/344)): Pick export formats directly from **File > Export type**.
