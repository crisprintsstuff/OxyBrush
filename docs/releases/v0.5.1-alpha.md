**OxyBrush 0.5.1-alpha** is a fast-follow maintenance and documentation release that refines Python plugin error diagnostics, expands the pure-Python `oxybrush` SDK with high-level mesh inspection dataclasses, bundles additional example plugins, and links the new 15-page GitHub Wiki. It's an alpha release: please [report issues](https://github.com/crisprintsstuff/OxyBrush/issues/new?template=bug_report.yml) or use **Help > Report a bug…** in the app.

## Changes in this release

**Python Plugin & Scripting Refinements**
- **Accurate Status Bar Error Diagnostics:** When an unhandled exception or syntax error occurs in a Python script, the status bar now displays the exact exception diagnostic (e.g. `AttributeError: ...`, `SyntaxError: ...`) extracted from the final line of `stderr` instead of truncating at the generic first line `Traceback (most recent call last):`.
- **`MeshStats` & `session.get_mesh_stats()`:** Added high-level mesh metrics dataclass to the Python SDK (`vertex_count`, `triangle_count`, `piece_count`, `subdivision_level`, `bounding_box_min`, `bounding_box_max`).
- **Convenience Methods on `Session`:** Added `session.voxel_remesh()`, `session.apply_stroke()`, `session.export_mesh()`, and flexible arguments on `session.add_primitive(kind=...)`.
- **Bundled `mesh_stats_reporter.py`:** Added an example plugin in `examples/plugins/` demonstrating `get_mesh_stats()` reporting metrics directly to the status bar and terminal.

**Documentation**
- **Official GitHub Wiki:** Launched the comprehensive [OxyBrush Wiki](https://github.com/crisprintsstuff/OxyBrush/wiki) covering sculpting brushes, multiresolution subdivision surfaces, voxel remeshing, masking & face groups, 3D posing gizmo, vertex color painting, Python plugin development, MCP AI agent tandem workflows, and 3D printing pipelines.

See the [changelog](https://github.com/crisprintsstuff/OxyBrush/blob/main/CHANGELOG.md) for full details.

## Known limitations

- Python plugins require Python 3 to be installed on the host system.
- Vertex color isn't included in exports yet, and remesh/decimate remove it.
- Transform gizmo uses world axes only.
